    Semana 2 · Punto 2(a)

    Código de conexión Web Bluetooth

    El mínimo indispensable para conectar y enviar un comando al robot. Está también como página aislada en minimo.html.

    // UUIDs definidos en el firmware (main.cpp)
const SERVICE = 0xFFE0;
const CHAR    = 0xFFE1;
let characteristic;

async function conectar() {
  // 1 · requestDevice
  const device = await navigator.bluetooth.requestDevice({
    filters: [{ services: [SERVICE] }]
  });
  // 2 · connect
  const server = await device.gatt.connect();
  // 3 · getPrimaryService
  const service = await server.getPrimaryService(SERVICE);
  // 4 · getCharacteristic
  characteristic = await service.getCharacteristic(CHAR);
}

async function enviar(cmd) {
  const bytes = new TextEncoder().encode(cmd);
  // 5 · writeValue
  await characteristic.writeValue(bytes);
}

// Uso: el navegador exige un gesto del usuario
btn.onclick = async () => {
  await conectar();
  await enviar("ad 200");
};
    1. requestDevice

      Abre el selector de dispositivos del navegador y sólo muestra los que anuncian el servicio FFE0. Devuelve un BluetoothDevice. Debe llamarse desde un clic (gesto del usuario).

    2. connect

      Establece la conexión GATT con el ESP32-C3. En el firmware se dispara onConnect y deviceConnected = true.

    3. getPrimaryService

      Busca dentro del robot el servicio primario FFE0, creado con createService(SERVICE_UUID).

    4. getCharacteristic

      Obtiene la característica FFE1 (el “buzón”), con permisos READ, WRITE, WRITE_NR y NOTIFY.

    5. writeValue

      Escribe los bytes UTF-8 del texto ("ad 200") en FFE1. El firmware lo recibe en onWrite y lo pasa a procesarComando(), que mueve los motores.

    Semana 3 · Punto 3

    Modo voz y modo gestos de mano

    No se entrena ningún modelo: se integran una API del navegador y una librería de visión por computador existentes. El trabajo propio es convertir su salida en comandos del robot.

    // Modo 3 · Voz: Web Speech API (nativa)
const rec = new (window.SpeechRecognition
  || window.webkitSpeechRecognition)();
rec.lang = "es-CO";
rec.continuous = true;       // escucha sin parar
rec.interimResults = true;   // parciales = más rápido

const MAPA = { adelante: "ad", atras: "at",
  derecha: "gh", izquierda: "ga", para: "stop" };

rec.onresult = (e) => {
  const texto = e.results[e.resultIndex][0].transcript;
  for (const palabra of normalizar(texto).split(" "))
    if (MAPA[palabra]) enviar(MAPA[palabra]);
};
rec.start();

// Modo 4 · Gestos: MediaPipe Gesture Recognizer
const { FilesetResolver, GestureRecognizer } =
  await import("…/tasks-vision/vision_bundle.mjs");
const files = await FilesetResolver.forVisionTasks(WASM);
const gr = await GestureRecognizer.createFromOptions(files, {
  baseOptions: { modelAssetPath: MODELO, delegate: "GPU" },
  runningMode: "VIDEO", numHands: 1
});

// En cada cuadro de la webcam:
const r = gr.recognizeForVideo(video, performance.now());
const gesto = r.gestures[0]?.[0]?.categoryName; // "Open_Palm"…
const mano  = r.landmarks[0];  // 21 puntos (x, y, z)
    1. SpeechRecognition

      El navegador convierte el audio del micrófono en texto. Con interimResults llegan resultados parciales mientras hablas, así que el comando sale antes de terminar la frase.

    2. Palabras clave → comando

      Se quitan tildes y mayúsculas, y cada palabra nueva se busca en el vocabulario (adelante→ad, derecha→gh, para→stop…). Si hay varias, gana la última. Cada palabra se procesa una sola vez.

    3. GestureRecognizer

      MediaPipe detecta la mano en cada cuadro de la webcam y devuelve 21 landmarks y un gesto clasificado (Open_Palm, Closed_Fist, Thumb_Up, Thumb_Down…).

    4. Landmarks → dirección

      Si sólo el índice está extendido, el vector del nudillo (punto 5) a la punta (punto 8) da la dirección: arriba ad, abajo at, derecha gh, izquierda ga. Palma o puño detienen el robot.

    5. Filtro de estabilidad

      Un gesto se envía sólo si se mantiene 3 cuadros seguidos (~100 ms) y es distinto al anterior. Si la mano desaparece más de 350 ms, el robot se detiene.
